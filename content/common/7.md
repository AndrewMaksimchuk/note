# Backus-Naur Form (BNF)  

Augmented BNF (ABNF)  

<https://www.ietf.org/rfc/rfc5234.txt>
Example: <https://github.com/toml-lang/toml/blob/1.0.0/toml.abnf>

An .abnf file contains a syntax specification written in Augmented Backus-Naur Form (ABNF).

ABNF is a standardized, text-based metalanguage (defined in RFC 5234) used by software developers, 
protocol designers, and computer scientists to define the formal grammar and structure of technical 
formats—such as network protocols (HTTP, SMTP, SIP), data formats, and programming language syntax.

## Example Syntax

An .abnf file defines rules using terminal and non-terminal symbols. For example, defining a basic US phone number grammar looks like this:

```abnf
phone-number = area-code "-" exchange "-" subscriber-number
area-code       = 3DIGIT
exchange        = 3DIGIT
subscriber-number = 4DIGIT
```
