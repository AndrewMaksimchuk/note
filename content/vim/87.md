# Window empty

To open an empty window side by side in Neovim:

```vim
:vnew
```

This creates a new empty buffer in a vertical split:

┌──────────────┬──────────────┐
│              │              │
│  file.txt    │   [empty]    │
│              │              │
└──────────────┴──────────────┘

## Useful commands

```vim
:vnew          " empty window on the side
:new           " empty window above/below
:vsplit file   " open file side by side
```
