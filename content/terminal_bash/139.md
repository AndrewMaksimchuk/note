# Standard Unix/Linux core utilities

## File & Directory Management

- cat: Concatenate and print file contents.
- cp: Copy files and directories.
- mv: Move or rename files and directories.
- rm: Remove (delete) files or directories.
- rmdir: Remove empty directories.
- mkdir: Create new directories.
- ls: List directory contents.
- dir: List directory contents (similar to ls).
- vdir: Verbose ls (equivalent to ls -l -b).
- ln: Create hard or soft (symbolic) links between files.
- link: Create a hard link to a file.
- unlink: Remove a specific file system name (call the unlink system call).
- touch: Update file timestamps, or create an empty file if it doesn't exist.
- truncate: Shrink or extend the size of a file to a specified size.
- mknod: Create block or character special files (device nodes).
- mkfifo: Create named pipes (FIFOs).
- mktemp: Create temporary files or directories safely.
- install: Copy files and set their attributes (permissions, ownership) in one step.
- stat: Display detailed file or file system status.
- shred: Securely overwrite a file to hide its contents before deletion.

## File Inspection & Text Processing

- head: Output the first part (lines or bytes) of files.
- tail: Output the last part of files.
- cut: Remove sections/columns from each line of files.
- paste: Merge lines of files side-by-side.
- join: Join lines of two files on a common field (like a database JOIN).
- comm: Compare two sorted files line by line.
- sort: Sort lines of text files.
- uniq: Report or omit repeated lines.
- shuf: Write random permutations of input lines.
- tac: Concatenate and print files in reverse line order.
- tr: Translate, squeeze, or delete characters.
- wc: Print newline, word, and byte counts for each file.
- nl: Number lines of files.
- fold: Wrap each input line to fit a specified width.
- fmt: Simple optimal text formatter.
- pr: Convert text files for printing (paginating/columnifying).
- ptx: Produce a permuted index of file contents.
- csplit: Split a file into context-determined pieces based on patterns.
- split: Split a file into fixed-size pieces.
- expand: Convert tabs to spaces.
- unexpand: Convert spaces to tabs.
- tsort: Perform a topological sort (resolve dependency graphs).

## Data Encoding & Formatting

- base32: Encode or decode data using Base32 representation.
- base64: Encode or decode data using Base64 representation.
- basenc: Encode or decode data using various algorithms (Base64, Base32, Base16, Hex, etc.).
- od: Dump files in octal, hexadecimal, or other formats.
- numfmt: Reformat numbers (e.g., convert bytes to human-readable format like 1K, 1M).

## Computes or checks cryptographic checksums:

- cksum: Compute CRC checksum and byte counts.
- sum: Legacy checksum tool.
- md5sum: MD5 algorithm.
- sha1sum: SHA-1 algorithm.
- sha224sum, sha256sum, sha384sum, sha512sum: SHA-2 family.
- sha3-224sum, sha3-256sum, sha3-384sum, sha3-512sum: SHA-3 family.
- shake128sum, shake256sum: SHAKE extendable-output functions (XOFs).
- b2sum: BLAKE2b algorithm.
- b3sum: BLAKE3 algorithm (extremely fast modern hash).
- hashsum: Multi-algorithm hashing tool wrapper.

## Path Manipulation

- basename: Strip directory and suffix from filenames.
- dirname: Strip non-directory suffix from file paths.
- pwd: Print current working directory.
- realpath: Resolve and print the absolute/canonicalized path.
- relpath: Print relative path from one directory to another.
- pathchk: Check if file names are valid or portable across POSIX systems.

## Permissions & System Security

- chmod: Change file access permissions (rwx).
- chown: Change file owner and group.
- chgrp: Change file group ownership.
- chcon: Change SELinux security context of a file.
- runcon: Run a command in a specified SELinux security context.
- chroot: Run a command or shell with a custom root directory.

## Shell Built-in Alternatives & Conditionals

- [: Equivalent to the test command; used for evaluating conditional expressions.
- test: Check file types and evaluate conditional statements.
- true: Do nothing, successfully (returns exit status 0).
- false: Do nothing, unsuccessfully (returns exit status 1).
- echo: Display a line of text.
- printf: Format and print data.
- yes: Output a string repeatedly until killed (useful for piping auto-confirmations).
- expr: Evaluate mathematical or string expressions.

## Process & System Info

- uname: Print system information (kernel version, architecture, OS).
- arch: Print machine hardware architecture (equivalent to uname -m).
- nproc: Print the number of processing units available.
- df: Report file system disk space usage.
- du: Estimate file space usage (disk usage per directory/file).
- sync: Flush file system buffers to disk.
- dd: Convert and copy a file (often used for raw block operations like flashing ISOs).

## System Execution & Environment Controls

- env: Run a command in a modified environment, or display current environment variables.
- printenv: Print all or specific environment variables.
- stdbuf: Modify buffering operations for standard streams (stdin, stdout, stderr).
- timeout: Run a command with a time limit.
- nice: Run a program with modified scheduling priority.
- nohup: Run a command immune to hangups (continues running after logout).
- tee: Read from standard input and write to standard output AND files simultaneously.

## User & Identity Tools

- whoami: Print effective user ID name.
- id: Print real and effective user and group IDs.
- groups: Print group memberships for a user.
- who: Show who is logged in.
- users: Print the user names of users currently logged in.
- logname: Print the user's login name.
- pinky: Lightweight finger lookup utility to get user info.
- hostid: Print the numeric identifier for the current host.

## Terminal & Display Controls

- tty: Print the file name of the terminal connected to standard input.
- stty: Change and print terminal line settings.
- dircolors: Setup color configuration for ls.
- sleep: Delay for a specified amount of time.
