# The double-parentheses construct (( ... ))

The (( ... )) construct permits arithmetic 
expansion and evaluation. In its simplest form, 
`a=$(( 5 + 3 ))` would set `a` to `5 + 3`, or `8`. 
However, this double-parentheses construct is also 
a mechanism for allowing C-style manipulation of 
variables in Bash, for example, `(( var++ ))`.

```sh
(( a = 23 ))
(( a++ ))
(( --a ))
(( t = a<45?7:11 ))   # C-style trinary operator
echo $((0x9abc)) # double-parentheses arithmetic expansion/evaluation
```

## Conditions without [ ]

```sh
if (( x > 10 )); then
    echo "big"
fi


(( x++ ))

if (( x % 2 == 0 )); then
    echo "even"
else
    echo "odd"
fi
```

## (( expression )) — arithmetic evaluation

Without $, Bash evaluates the expression as a command.

```sh
x=10

(( x++ ))
echo "$x"
11
```

The important difference is that (( ... )) has an exit status based on the result:

```sh
(( 1 + 1 ))
echo "$?"
0
```

- arithmetic result non-zero → exit status 0 (success)
- arithmetic result zero → exit status 1 (failure)

This makes (( ... )) especially useful for conditions:

```sh
if (( x > 10 )); then
    echo "x is large"
fi

while (( counter < 10 )); do
    echo "$counter"
    (( counter++ ))
done
```

## $(( expression )) — arithmetic expansion

The $ means "calculate this and substitute the result here."

```sh
x=10
y=3

echo $((x + y))
13

result=$((x * y))
echo "$result"

echo "The result is $((10 + 20))"
filename="file_$((x + 1)).txt"
```

One especially nice Bash feature is that inside (( )) you normally don't need $ before variables:

```sh
(( x = y + 10 ))
```
