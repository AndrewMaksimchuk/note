# condition && command1 || command2

This mean:

```sh
if condition succeeds
    run first command
else
    run second command
```

Is not exactly equivalent to if/else, 
because if command1 itself fails, 
command2 will also execute.

```sh
true && false || echo "oops"
oops
```

The interesting part is that commands have exit statuses, 
and && / || operate on those statuses.

```sh
(( x < 0 )) && echo "negative" ||
(( x == 0 )) && echo "zero" ||
echo "positive"
```
