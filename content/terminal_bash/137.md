# Nice debugging setup

```sh
set -euxo pipefail
```

And if you want really clear traces


```sh
PS4='+ ${BASH_SOURCE}:${LINENO}: '
set -x
```

Then you get something like

```sh
+ ./main.sh:12: echo 'Starting'
Starting
+ ./main.sh:13: do_something
+ ./functions.sh:27: curl ...
```

That BASH_SOURCE + LINENO combination is fantastic 
for finding exactly where a script failed, 
especially when you have multiple sourced .sh files.
