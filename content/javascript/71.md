# Array fix size

```javascript
var _JsArray_map = F2(function(func, array)
{
    var length = array.length;
    var result = new Array(length);

    for (var i = 0; i < length; i++)
    {
        result[i] = func(array[i]);
    }

    return result;
});
```

```javascript
var result = new Array(length);
```

It means:
"Create an empty array that already has the required size."

1. The size is already known

The input array:

already tells us the output size.

always returns an array with the same number of elements:

input length  = 5
output length = 5

2. Avoid growing the array repeatedly

With:

```javascript
result.push(value);
```

the JavaScript engine may need to:

create array
    ↓
add item
    ↓
resize internal storage
    ↓
add item
    ↓
resize again

With:

```javascript
new Array(length)
```

the engine knows the expected size.

allocate 5 slots
    ↓
fill slots
