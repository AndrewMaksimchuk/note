# A very small language subset

Elm's JavaScript runtime intentionally sticks to a conservative subset of JavaScript:

var
function
for
object literals
arrays

It avoids features like:

class
arrow functions
async/await
destructuring
optional chaining

This makes the runtime predictable and easy to audit.

One thing you'll notice if you continue reading compiler implementations 
(Elm, Git, Lua, SQLite, CPython) is that many of them don't chase modern 
language features. Their code often looks "old-fashioned," but it's 
intentionally conservative because these projects prioritize correctness, 
portability, and long-term maintainability over using the latest syntax.
