# Property font-size

```css
html {
    font-size: calc(0.3vw + 0.7em);
}
```

Sets the font size responsively, based on both the 
viewport width and the element's inherited font size.

- 0.3vw = 0.3% of the viewport width.
- 0.7em = 70% of the current/inherited font size.
- calc(...) adds them together.

```css
font-size: clamp(12px, calc(0.3vw + 0.7em), 18px);
```

This means:
- 12px → minimum font size
- calc(0.3vw + 0.7em) → preferred responsive size
- 18px → maximum font size

One important detail: because you're using em, the result depends on the element's inherited font size. 
If you want the responsive sizing to be based on the root font size instead, use rem:

```css
font-size: clamp(14px, calc(0.3vw + 0.7rem), 20px);
```
