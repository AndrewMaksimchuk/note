# Result

A Result is the result of a computation that may fail. 
This is a great way to manage errors in Elm.

```elm
type Result error value
    = Ok value
    | Err error
```

A Result is either Ok meaning the computation succeeded, 
or it is an Err meaning that there was some failure.

## Mapping

```elm
map : (a -> value) -> Result x a -> Result x value
```

Apply a function to a result. If the result is Ok, 
it will be converted. If the result is an Err, 
the same error value will propagate through.

```elm
map sqrt (Ok 4.0)          == Ok 2.0
map sqrt (Err "bad input") == Err "bad input"
```

## Handling Errors

```elm
withDefault : a -> Result x a -> a
```

If the result is Ok return the value, 
but if the result is an Err then return 
a given default value. The following examples 
try to parse integers.

```elm
Result.withDefault 0 (Ok 123)   == 123
Result.withDefault 0 (Err "no") == 0
```
