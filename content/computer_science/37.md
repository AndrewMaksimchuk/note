# DNS — перетворення імен на IP-адреси

DNS (Domain Name System) — система, яка дозволяє знаходити сервери за доменними іменами.

Спрощено процес виглядає так:
1. Ти вводиш google.com.
2. Комп'ютер звертається до DNS-сервера.
3. DNS-сервер шукає відповідну IP-адресу.
4. Повертає її комп'ютеру.
5. Браузер використовує отриману адресу для підключення до сервера.

DNS використовує власний мережевий протокол. Зазвичай це UDP на порту 53, хоча також використовується TCP.

DNS-записи — це правила, які визначають, яку інформацію DNS-сервер повинен повернути для певного доменного імені.

1. A — домен → IPv4-адреса
Запис A (Address) пов'язує доменне ім'я з IPv4-адресою.

2. AAAA — домен → IPv6-адреса
Запис AAAA (вимовляється «quad-A») працює подібно до A, але повертає IPv6-адресу.

3. CNAME — домен → інший домен
Тут уже цікавіше.

CNAME (Canonical Name) — це псевдонім, який вказує на інше доменне ім'я, а не безпосередньо на IP-адресу.

## Як DNS обробляє записи

```
A
server.home.arpa
↓ IPv4-адреса
192.168.1.10


AAAA
server.home.arpa
↓ IPv6-адреса
2001:db8::10


CNAME
dashboard.home.arpa
↓ Інше доменне ім'я
server.home.arpa
```
