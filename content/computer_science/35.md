# Statement and an expression

At its core, the distinction between a statement and an expression comes down to one question: Does it evaluate to a value, or does it perform an action?

## Quick Summary

- Expression: A piece of code that evaluates to a value.
- Statement: A unit of code that executes an action or instruction.

The Litmus Test: Can you pass it as an argument to a function, assign it to a variable, or print it directly?

- If yes -> It's an expression.
- If no  -> It's a statement.

## Detailed Comparison
