# Формальний доказ (formal proof)

Це математично обґрунтоване підтвердження того, що певне твердження є істинним, побудоване за чітко визначеними правилами логіки.

У програмуванні це означає можливість довести, що програма або функція задовольняє певні властивості, а не просто перевірити, що вона працює на кількох прикладах.

Уявімо функцію:

```javascript
function absoluteValue(x: number): number {
    return x < 0 ? -x : x;
}
```

Ми хочемо підтвердити властивість:

```
f(x) \geq 0
```

Тобто результат функції завжди невід'ємний.

Звичайне тестування:

```javascript
expect(absoluteValue(-5)).toBe(5);
expect(absoluteValue(0)).toBe(0);
expect(absoluteValue(7)).toBe(7);
```


Ми перевірили три конкретні випадки. Але це не доводить, що властивість виконується для всіх допустимих значень x.

Формальний доказ:

Ми розглядаємо всі можливі випадки:
1. Якщо \(x < 0\), функція повертає \(-x\). Оскільки \(x\) від'ємне, \(-x > 0\).
2. Якщо \(x \geq 0\), функція повертає \(x\), яке вже невід'ємне.

Отже, в обох випадках:

```
f(x) \geq 0
```

Це вже логічний доказ властивості, а не перевірка окремих прикладів.
